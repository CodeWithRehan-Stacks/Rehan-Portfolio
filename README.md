# Rehan Bhai - Premium Portfolio

A futuristic, cinematic, and high-end personal portfolio website built with React, Tailwind CSS, Framer Motion, and GSAP.

## Tech Stack

- **React** - UI Framework
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations
- **GSAP** - Complex Transitions
- **Lenis** - Smooth Scrolling
- **Lucide & React Icons** - Icons
- **Typewriter Effect** - Dynamic Text

## Project Structure

```bash
src/
├── components/
│   ├── About/        # About section & Counters
│   ├── Contact/      # Contact form & Info
│   ├── Footer/       # Minimal footer
│   ├── Github/       # GitHub stats visualization
│   ├── Hero/         # Hero section & Typewriter
│   ├── Layout/       # SmoothScroll & CustomCursor
│   ├── Navbar/       # Responsive navigation
│   ├── Projects/     # Glassmorphism project cards
│   ├── Skills/       # Animated tech stack
│   ├── Testimonials/ # Floating feedback cards
│   └── Timeline/     # Journey & Vision timeline
├── utils/            # Helper functions (cn utility)
├── App.jsx           # Main assembly & Loading screen
├── index.css         # Global styles & Tailwind
└── main.jsx          # Entry point
```

## Setup Instructions

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```

## Deployment

To deploy on Vercel:
1. Push the code to a GitHub repository.
2. Connect the repository to Vercel.
3. Use `npm run build` as the build command and `dist` as the output directory.
